# Agent时延统计范围

两个主指标使用同一批实际作答的题目。得分、召回等质量指标仍覆盖该测评结果的全部答卷。

|执行方式|Agent计时范围|
|---|---|
|首次运行、整批重跑|本次实际执行且已结束的题；执行失败也计入，未开始的取消题排除|
|续跑、失败题补做|只计本次实际执行的题；继承答卷不进入分母|
|单题重测|本次单题|
|只补裁判评分|无Agent作答，两项主时延为空，页面显示“不适用”|
|运行中或取消|截至当前检查点的执行时间和已结束题数，属于阶段数据|

- 并发吞吐折算时延＝（从本次QA阶段启动到最后一个实际Agent工作结束的墙钟－仅因裁判积压而暂停派发、且Agent池已无活动任务的等待）÷本次已结束题数。
- 平均任务完成时间＝本次每题作答墙钟的算术平均。取到测评执行槽位开始，到收齐回答和证据结束；不含裁判；包含产品/模型服务内排队、工具及网络耗时。等待测评槽位只进入整批吞吐，不加入每题耗时。
- 两者会受并发数影响，不能预期接近。均衡负载下，单题平均约为吞吐折算值乘有效并发数；长尾、派发、持久化等使该关系并非恒等式。
- 保留实际QA墙钟、裁判独占等待及全答卷平均耗时供核对。与Agent并行的裁判耗时不能直接从墙钟相减，也不能凭现有遥测消除两者资源竞争产生的影响。

新运行将执行题目ID、继承题数和裁判独占等待写入QA阶段。总进度`agent_completed`仍包含继承答卷，不能用于本次计时分母。

历史续跑根据`resume_context.inherited_qa_ids`区分本次作答；历史没有独立记录裁判积压等待时，保留实际阶段值，并在页面说明无法扣除。没有独立Agent阶段墙钟的历史数据不估算吞吐。

汇总列表、详情、格式3长轨迹结果采用同一计时函数，读取旧结果时重算投影，保留原答卷和评分。前端保留后端明确的空值，避免从继承题再次补出错误均值。启动扫描只读取运行状态，不计算历史时延；旧非格式3快照的列表不展示未经重算的旧时延，打开详情后重算，避免列表浏览加载数GB轨迹。

真实Q4续跑核验：1013份答卷中继承979题，本次执行34题。观测阶段4300.3551秒，吞吐126.481秒/题，单题均值425.4966秒；全答卷平均342.6915秒另列。该历史运行未记录可扣除的裁判积压等待。
